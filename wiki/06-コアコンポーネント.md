# 🧩 06. コアコンポーネント

## 6.1 `review-page` の中核

### A. 授業検索API: `app/api/review-ask/route.ts`

- OpenAI Responses API + Function Calling の制御
- `tool_choice='required'` で DB根拠回答を強制
- 主要ツール
  - `get_my_affiliation`
  - `search_subjects_by_name`
  - `get_subject_rollup`
  - `top_subjects_by_metric`
  - `search_subjects_by_tags`

(参照: `../apps/review-page/app/api/review-ask/route.ts:479-633`、`../apps/review-page/app/api/review-ask/route.ts:1345-1477`)

### B. 授業投稿API: `app/api/course-reviews/route.ts`

- 入力検証（教員必須、コメント30文字以上、評価1-5）
- マスタ確定（users, universities, subjects）
- レビュー保存後にタグ・ジョブ・dirtyフラグを更新

(参照: `../apps/review-page/app/api/course-reviews/route.ts:266-354`、`../apps/review-page/app/api/course-reviews/route.ts:426-523`)

### C. 投稿UI: `app/course_reviews/page.tsx`

- LIFF初期化、ユーザーID解決、所属自動補完
- ハッシュタグ入力（最大5個、候補表示、人気タグ表示）
- 送信時に `review-moderation` を経由して投稿

(参照: `../apps/review-page/app/course_reviews/page.tsx:254-334`、`../apps/review-page/app/course_reviews/page.tsx:937-1014`)

## 6.2 `line-ai-bot` の中核

### D. Webhook: `api/webhook.js`

- LINE署名検証
- `chat_messages` 保存
- メッセージ内容で経路分岐
  - `#` を含む: `review-ask`
  - 企業キーワード: `company-ask`
  - 授業キーワード: `review-ask`
  - それ以外: 雑談生成

(参照: `../apps/line-ai-bot/api/webhook.js:41-45`、`../apps/line-ai-bot/api/webhook.js:488-515`)

## 6.3 バッチ群

### E. Embeddings バッチ

- `embedding_jobs` と `company_embedding_jobs` を処理
- `content_hash` で冪等更新
- AIフラグ付きレビューを除外

(参照: `../apps/review-page/app/api/batch/embeddings/run/route.ts:14-30`、`../apps/review-page/app/api/batch/company-embeddings/run/route.ts:14-23`)

### F. Rollups バッチ

- `subject_rollups` / `company_rollups` の統計値と要約を更新
- 要約の埋め込みも差分更新

(参照: `../apps/review-page/app/api/batch/rollups/run/route.ts:16-24`、`../apps/review-page/app/api/batch/company-rollups/run/route.ts:14-19`)

## 6.4 `subject-browser` の中核

- 大学選択 → 科目一覧/検索 → 科目詳細（rollup表示）
- 公開APIは `app/api/public/*` に限定

(参照: `../apps/subject-browser/app/page.tsx:48-121`、`../apps/subject-browser/app/subjects/[subjectId]/page.tsx:108-126`)
